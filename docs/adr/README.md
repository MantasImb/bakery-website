# Architecture Decision Records

This directory records durable architecture and product decisions.

Create an ADR when a decision is:

- Hard to reverse later.
- Surprising without context.
- Driven by real trade-offs between reasonable options.

Use sequential filenames such as `0006-short-decision-slug.md`. Keep ADRs short; record what was decided, why it matters, meaningful alternatives, and non-obvious consequences.

Do not use ADRs for temporary implementation tasks, obvious preferences, or domain vocabulary that belongs in [`../../CONTEXT.md`](../../CONTEXT.md).
